## 📂 Repository Structure

This repository is organized progressively, starting from data cleaning and moving towards advanced deep learning and specialized systems.

Click on any folder below to see the specific notebooks and code implementation.

### [📁 01_Data_Preprocessing](./01_Data_Preprocessing)
*Foundational techniques for cleaning, structuring, and preparing raw datasets.*
- **Techniques:** Missing value handling, categorical encoding, feature scaling, and normalization.

### [📁 02_Classical_ML](./02_Classical_ML)
*Implementation of traditional supervised learning models for continuous and categorical predictions.*
- **Models:** Multiple Linear Regression, Logistic Regression, SVM, Decision Trees, Random Forest.

### [📁 03_Boosting_Models](./03_Boosting_Models)
*Advanced ensemble techniques designed for high accuracy and performance.*
- **Models:** LightGBM vs. XGBoost comparisons.

### [📁 04_Unsupervised_Learning](./04_Unsupervised_Learning)
*Algorithms used to find hidden patterns or intrinsic structures in input data.*
- **Models:** Principal Component Analysis (PCA), Clustering algorithms.

### [📁 05_Deep_Learning](./05_Deep_Learning)
*Neural network architectures for complex pattern recognition.*
- **Models:** Artificial Neural Networks (ANN), Recurrent Neural Networks (RNN).

### [📁 06_Advanced_Topics](./06_Advanced_Topics)
*Specialized machine learning applications for specific industry use cases.*
- **Models:** Recommendation Systems, Time Series Forecasting, NLP.

## 🛠️ How to Use This Repository

1. Clone the repository:
```bash
   git clone https://github.com/Shivas28/ML-Portfolio.git
```
2. Navigate into the specific topic folder you want to explore.
3. Launch Jupyter Notebook:
```bash
   jupyter notebook
```
